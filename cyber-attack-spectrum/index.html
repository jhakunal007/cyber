Problem Statement & Motivation

The Limitations of Traditional IDS

Why deterministic, crisp rule sets fail in modern polymorphic cyber warfare—and how Soft Computing bridges the gap.

Traditional Crisp / Rule-Based IDS

Snort, Suricata, Binary Thresholds

  • Brittle Binary Boundaries: A hard threshold at 100 pps marks 99.9 pps as benign, enabling stealth evasion.
  • Blind to Zero-Day Threats: Cannot classify unseen attack mutations without pre-existing signature updates.
  • High False Alarm Rate (FAR > 4.8%): Floods security analysts with false alerts during legitimate flash crowds.
  • Curse of Dimensionality: Chokes on 78+ raw telemetry dimensions without intelligent feature selection.

Our Soft Computing Framework

Hybrid ANFIS + GA Optimization

  • Continuous Truth Spectrum: Models ambiguity with Fuzzy Logic membership degrees [0, 1] for smooth risk scoring.
  • Zero-Day Anomaly Detection: Deep neural embeddings detect polymorphic behavioral drift without exact signatures.
  • Ultra-Low False Alarms (0.28%): Distinguishes legitimate burst spikes from coordinated volumetric assaults.
  • GA Feature Reduction (65%): Strips redundant headers to accelerate flow classification down to 1.42ms.

Academic Publication & Project Dossier

Classifying Cyber Attack Spectrum Using Soft Computing

Abstract: Modern cyber threats exhibit non-linear dynamics, polymorphic mutation, high dimensional velocity, and zero-day stealth that fundamentally evade traditional crisp/deterministic rule-based intrusion detection systems (IDS). This research presents a comprehensive multi-tier framework for classifying the extensive Cyber Attack Spectrum using Soft Computing paradigms—specifically integrating Fuzzy Inference Systems (FIS), Adaptive Neuro-Fuzzy Inference Systems (ANFIS), Deep Recurrent Neural Networks (LSTM), and Genetic Algorithm (GA) feature selection. Evaluated on benchmark cybersecurity corpora (NSL-KDD, CIC-IDS2017, and UNSW-NB15), our proposed hybrid ANFIS-GA architecture achieves a 99.14% classification accuracy with a 0.28% false alarm rate across 8 distinct attack spectrum bands.
